## 本版变更（v1.1.0）

### 更新类型

- [x] 首次 DLL 化（基准版本）

### 变更内容

#### 新增
- **DLL 化**：将 DbAccessCustom 封装为 DBService.dll
- **对外头文件**：新增 `include/` 目录，包含 5 个自包含的公共头文件
- **DLL 导出宏**：新增 `dbservice_global.h`，定义 `DBSERVICE_EXPORT` 宏
- **版本号**：新增 `DBService::currentVersion()` 静态方法
- **日志配置**：新增 `LogConfig::loadFromIni()` 从外部 ini 文件加载日志配置
- **日志分组**：空 `serviceName` 默认分组为 `"default"`
- **连接名递增**：`QDBConnection` 每次重连使用递增连接名，避免句柄复用崩溃

#### 修复
- **信号槽未连接问题**：电脑重启后数据库服务未启动时，`DBService::init` 即使失败也返回 `true`，且信号槽在 init 前已连接，确保后台重连后仍能触发 `sigExecFinished`

#### 变更
- **接口精简**：移除 `Standard` 模式构造函数 `DBService(const DBTaskManagerConfig&)`，`extractData` 从 public 移至 private
- **C++ 标准**：从 C++17 降为 C++11
- **编译环境**：Qt 5.0+，MinGW 8.1.0 / MSVC

#### 移除
- 移除 `loadStandardConfig()` 方法
- 移除 `DbAccessCustom/` 包装目录，`DBService/` 和 `DbAccess/` 直接为同级目录

### 兼容性

- [x] 向后兼容
- [x] 业务项目无需修改代码

### 影响范围

- `include/DBService.h` — 新增 `currentVersion()`
- `include/DBLogManager.h` — 新增 `LogConfig` 结构体
- `include/dbservice_global.h` — 新增
- `config/LogConfig.ini` — 新增
