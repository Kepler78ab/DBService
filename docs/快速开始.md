# DBService v1.5.1 快速使用说明

## 引用方式

### 1. 拷贝文件到业务项目

> Debug 和 Release 使用不同 DLL 名称（`DBServiced.dll` / `DBService.dll`），避免混用。

```
业务项目/
├── include/                    ← 拷贝 include/ 目录（Debug/Release 共用）
│   ├── DBService.h
│   ├── DBServicePool.h         ← v1.5.1 新增
│   ├── DBLogManager.h
│   ├── DBServiceStruct.h
│   ├── DBConfig.h
│   └── dbservice_global.h
├── lib/
│   ├── debug/                  ← 拷贝 Debug DLL + .a
│   │   ├── DBServiced.dll
│   │   └── libDBServiced.a
│   └── release/                ← 拷贝 Release DLL + .a
│       ├── DBService.dll
│       └── libDBService.a
└── config/
    ├── DBConfig.ini            ← 数据库配置
    └── LogConfig.ini           ← 日志配置
```

### 2. .pro 文件配置

```pro
INCLUDEPATH += $$PWD/include

# Debug / Release 分开链接（DLL 名称不同）
CONFIG(debug, debug|release) {
    LIBS += -L$$PWD/lib/debug -lDBServiced
} else {
    LIBS += -L$$PWD/lib/release -lDBService
}
```

### 3. 运行时部署

Debug 模式将 `DBServiced.dll` 放在 exe 同级目录，Release 模式放 `DBService.dll`。

## 使用示例

### 单实例用法（DBService）

```cpp
#include <DBService.h>
#include <DBLogManager.h>

// 1. 从配置文件加载数据库配置
auto config = DBService::loadSimpleConfig("config/DBConfig.ini");

// 2. 创建并初始化 DBService（WorkerThread 模式，不阻塞 UI）
DBService* db = new DBService(config, TaskThreadModel::WorkerThread, this);

// 3. 启动服务
db->start();

// 4. 创建日志管理器并启动
DBLogManager* logMgr = new DBLogManager(this);
logMgr->start("service_log", 30000);

// 5. 连接信号
connect(db, &DBService::sigExecFinished, this, [](const DBServiceResult& result) {
    qDebug() << "执行结果:" << result.isSuccess << result.errMsg;
});

// 6. 执行 SQL
QVector<SqlTuple> sqlList;
sqlList.append(SqlTuple::create("tag1", "SELECT * FROM users"));
db->onExecSqlList(sqlList);
```

### 并发用法（DBServicePool，v1.5.1 新增）

```cpp
#include <DBServicePool.h>

// 1. 创建连接池（4 个实例并发）
DBConfig dbConfig;
dbConfig.dbName = "mydb";
dbConfig.host = "127.0.0.1";
dbConfig.port = 3306;
dbConfig.user = "root";
dbConfig.password = "123456";

DBServicePool* pool = new DBServicePool(dbConfig, 4, DBServiceType::Standard, this);

// 2. 连接一个信号即可（聚合转发，serviceName 可溯源）
connect(pool, &DBServicePool::sigExecFinished, this, [](const DBServiceResult& result) {
    // result.serviceName 可区分来自 pool_0 / pool_1 / ...
    qDebug() << result.serviceName << result.isSuccess;
});

// 3. 初始化并启动
pool->init();
pool->start();

// 4. 分发任务（自动选择最空闲实例）
pool->execSql("task_001", "hist", "SELECT * FROM histtest", false);

// 扩容只需改 poolSize，调用方代码零改动
// DBServicePool pool2(cfg, 8);  // 4 → 8 路并发
```

### 手动配置方式

```cpp
DBConfig dbConfig;
dbConfig.dbName = "mydb";
dbConfig.host = "127.0.0.1";
dbConfig.port = 3306;
dbConfig.user = "root";
dbConfig.password = "123456";

// Reliable 模式：SQL 正确时 100% 执行，永不丢失
DBService* db = new DBService(DBServiceType::Reliable, dbConfig, this);
db->start();
```

## 服务类型说明

| 类型       | 重试策略        | 适用场景                     |
|------------|----------------|------------------------------|
| Reliable   | ForeverRetry   | 日志/审计等必须落库           |
| HighPerf   | 批量入队+短间隔 | 高频写入（如实时数据采集）     |
| Standard   | 有限重试(3次)   | 通用业务                     |
| Unreliable | NoRetry        | 非关键查询，一次即弃           |

## 线程模式说明

| 模式          | 枚举值                                   | 行为                                              |
|---------------|------------------------------------------|---------------------------------------------------|
| 主线程（默认） | `TaskThreadModel::MainThread`            | TaskManager 在主线程运行，SQL 阻塞会卡 UI          |
| 子线程        | `TaskThreadModel::WorkerThread`          | TaskManager 移入子线程，SQL 阻塞不影响 UI          |

### 选择建议

- **旧项目升级**：不传参或传 `MainThread`，行为与 v1.1 完全一致，零改动
- **新项目 / 有 UI 的项目**：推荐 `WorkerThread`，避免数据库超时导致界面冻结
- **后台无 UI 服务**：`MainThread` 即可，无需额外线程开销
- **DBServicePool 固定使用 WorkerThread**，无需手动指定

### 注意事项

- `sigExecFinished` 始终在主线程触发（跨线程自动 `QueuedConnection`），槽函数中可直接操作 UI
- `WorkerThread` 模式下，若在 `sigExecFinished` 槽函数中重新投递 SQL，需注意栈深度

## 接收结果

### 方式一：直接使用原始 JSON（推荐）

`sigExecFinished` 返回的 `DBServiceResult` 包含 `rawJson` 字段（`QJsonDocument`），**零转换**直接访问：

```cpp
connect(db, &DBService::sigExecFinished, this, [](const DBServiceResult& result) {
    if (result.isSuccess) {
        QJsonObject root = result.rawJson.object();
        QJsonArray users = root["users"].toArray();
        for (const auto& user : users) {
            qDebug() << user.toObject()["name"].toString();
        }
    } else {
        qWarning() << "Error:" << result.errMsg;
    }
});
```

### 方式二：按需提取结构化数据（UI 绑定）

```cpp
connect(db, &DBService::sigExecFinished, this, [](const DBServiceResult& result) {
    if (!result.isSuccess) return;
    auto data = DBService::extractData(result.rawJson);
    auto rows = data["users"].value<QVector<QVariantMap>>();
    for (const auto& row : rows) {
        ui->table->addRow(row["name"].toString(), row["age"].toInt());
    }
});
```

### 方式三：兼容旧 sigRawResult 调用方

```cpp
connect(db, &DBService::sigExecFinished, this, [](const DBServiceResult& res) {
    auto raw = res.toRawResult();     // 拿到 DBServiceRawResult
    sendToWebSocket(raw.resultJson);  // 回调内一行不改
});
```

## 自定义 taskId

```cpp
// 用 IPC requestId 作为 taskId 投递
m_dbService->onExecSqlList(sqlList, ipcRequestId);

// sigExecFinished 中精确匹配
connect(db, &DBService::sigExecFinished, this, [](const DBServiceResult& result) {
    if (result.taskId == ipcRequestId) {
        // 精确匹配到请求
    }
});
```

## 大数据量查询建议

- **优先使用 `rawJson`**，避免不必要的 `extractData` 转换
- **SELECT 加 LIMIT/OFFSET 分页**，减少单次结果集大小
- 一次查询万行以上数据时，关注内存占用（参考 [内存优化方案](docs/progress_docs/内存优化.md)）
