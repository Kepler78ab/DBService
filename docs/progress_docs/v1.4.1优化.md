# DBService v1.4.1 性能优化方案

> 版本：v1.4.1 | 日期：2026-07-28
> 针对 P0 之后剩余的深拷贝和运行时开销做进一步优化，全部兼容 C++11。

---

## 一、优化项清单

| # | 优化项 | 类型 | 预期收益 | 改动行数 |
|---|--------|------|---------|:--------:|
| 1 | BatchBuffer: `QQueue<DBTask>` → `QQueue<shared_ptr<DBTask>>` | 深拷贝消除 | 批量路径 3 次深拷贝 → 1 次 | 4 处 |
| 2 | pendingTasks 提取加 `std::move` | 深拷贝消除 | 省一次 QVector\<SqlTuple\> 拷贝 | 1 行 |
| 3 | Release 编译加 `QT_NO_DEBUG_OUTPUT` | 运行时开销 | 日志格式化全编译消除 | 5 行 |
| 4 | executeSqlUnit 行追加加 `std::move` | 隐式共享 detach | 每行少一次 QJsonObject ref 操作 | 1 行 |
| 5 | DBLogManager flushToFile 加 `std::move` | 深拷贝消除 | 刷盘时零复制 DBServiceResult | 2 行 |

## 二、详细改动

### 2.1 BatchBuffer → shared_ptr

**当前问题**：

`m_batchBuffer` 是 `QQueue<DBTask>`，而主队列 `m_taskQueue` 已改 `shared_ptr`。任务走批量路径时经历 3 次深拷贝：

```
① m_batchBuffer.enqueue(task)           → DBTask 深拷贝入队
② DBTask task = m_batchBuffer.dequeue() → DBTask 深拷贝出队
③ node.task = std::make_shared<DBTask>(task) → DBTask 深拷贝构造共享指针
```

**改法**：

```cpp
// .h
QQueue<std::shared_ptr<DBTask>> m_batchBuffer;

// .cpp — 入队
auto taskPtr = std::make_shared<DBTask>(task);
taskPtr->requestTime = ...;
m_batchBuffer.enqueue(taskPtr);

// .cpp — 出队
auto taskPtr = m_batchBuffer.dequeue();
node.task = taskPtr;
```

**改动后路径**：

```
① std::make_shared<DBTask>(task) → 1 次深拷贝构造
② dequeue → 指针复制，零拷贝
③ node.task = taskPtr → shared_ptr 复制，零拷贝
```

**文件**：`dbtaskmanager.h:160`、`dbtaskmanager.cpp:91,190,209`

---

### 2.2 pendingTasks 提取加 std::move

**当前问题**：

```cpp
originalTupleList = it.value();    // 深拷贝
m_pendingTasks.erase(it);          // 然后擦掉原数据，拷贝出来的数据是唯一的
```

**改法**：

```cpp
originalTupleList = std::move(it.value());  // 移出，零拷贝
m_pendingTasks.erase(it);
```

**文件**：`dbservice.cpp:245`

---

### 2.3 Release 编译加 QT_NO_DEBUG_OUTPUT

**问题**：发布版中所有 `qDebug()` / `qWarning()` 字符串格式化仍在执行，然后被默认 handler 丢弃。

**改法**：

```pro
CONFIG(release, debug|release) {
    DEFINES += QT_NO_DEBUG_OUTPUT QT_NO_WARNING_OUTPUT
}
```

**文件**：`DBService.pro`

每次 SQL 执行约 5~6 次 `qDebug`/`qWarning` 调用：

| 调用点 | 次数 |
|--------|:----:|
| pushTask 日志 | 1 |
| processTask 执行日志 | 1 |
| 成功/失败日志 | 1~2 |
| scheduleNextTask 日志 | 1 |
| DBLogManager flush 日志 | 1 次/刷盘 |

---

### 2.4 executeSqlUnit 行追加加 std::move

**当前问题**：

```cpp
QJsonObject obj;
// ... 填充 obj ...
resultArray.append(obj);    // 拷贝 obj，原 obj 丢弃
```

QJsonObject 是隐式共享的，Append 时 bump ref count → detach，有额外开销。

**改法**：

```cpp
resultArray.append(std::move(obj));  // 转移所有权，零额外开销
```

**文件**：`qdbconnection.cpp:264`

---

### 2.5 DBLogManager flushToFile 加 std::move

**当前问题**：

```cpp
QMap<QString, QVector<DBServiceResult>> groups;
for (const DBServiceResult& result : batch) {     // batch 局部独占
    groups[result.serviceName].append(result);     // 拷贝整个 DBServiceResult
}
```

**改法**：

```cpp
for (DBServiceResult& result : batch) {   // const →
    groups[result.serviceName].append(std::move(result));
}
```

**文件**：`DBLogManager.cpp:136`
